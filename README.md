# nest-mongoose-crud Documentation

This repository hosts the documentation site for the `nest-mongoose-crud`
package, built with Docusaurus.

## Local Development

```bash
npm install
npm run start
```

Then open the local site at `http://localhost:3000`.

## Build

```bash
npm run build
```

## Notes

- The docs use `Product` and `Category` example schemas to demonstrate
  common NestJS + Mongoose CRUD patterns.
- The site is configured for package documentation and does not expose a
  blog by default.
